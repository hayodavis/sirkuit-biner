Memahami Bilangan Biner & IPv4

Pelajari bagaimana komputer memproses angka menggunakan sakelar digital dan bagaimana ia diterapkan pada alamat IP.

1. Apa itu Bilangan Biner?

Manusia berhitung menggunakan 10 angka (0-9). Namun, komputer hanya memahami dua kondisi kelistrikan: Ada Arus (1) dan Tidak Ada Arus (0). Sistem dua angka ini disebut Biner (Basis 2).

Setiap satu angka 0 atau 1 disebut Bit. Kumpulan dari 8 Bit disebut 1 Byte.

2. Alamat IPv4

IPv4 terdiri dari 32 bit yang dibagi menjadi 4 Oktet (1 oktet = 8 bit), dipisahkan dengan tanda titik.

Desimal: 192 . 168 . 1 . 10
Biner: 11000000 . 10101000 . 00000001 . 00001010

3. Cara Konversi Biner ke Desimal

Nilai dihitung dari kanan ke kiri sebagai perpangkatan angka 2. Jika bit bernilai 1 (Hidup), angkanya dijumlahkan. Jika 0 (Mati), diabaikan.

Bit 8Bit 7Bit 6Bit 5Bit 4Bit 3Bit 2Bit 1
1286432168421
10101000

Contoh Perhitungan Biner "10101000":

=> (1x128) + 0 + (1x32) + 0 + (1x8) + 0 + 0 + 0

=> 128 + 32 + 8 = 168

4. Praktik dan Evaluasi

Metode Pengurangan (Desimal -> Biner)

  • 192 - 128 = 64 (Bisa -> 1)
  • 64 - 64 = 0 (Bisa -> 1)
  • 0 - 32 (Tidak -> 0)
Hasil: 11000000

  5. Hati-hati! Jika salah, mobil "Mogok" dan soal otomatis diacak ulang.

Integrasi Google Sheets

Masukkan URL Web App dari Google Apps Script untuk merekap nilai ke Google Sheets.

Cara Membuat Script (Klik)
  1. Buat Google Sheets baru (Header: Nama, Materi, Nilai, Tanggal).
  2. Klik Ekstensi > Apps Script. Paste kode ini:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  sheet.appendRow([e.parameter.nama, e.parameter.materi, e.parameter.nilai, e.parameter.tanggal]);
  return ContentService.createTextOutput("Success");
}

Simpan > Terapkan > Deployment Baru (Aplikasi Web) > Akses: Siapa Saja > Copy URL ke kotak di atas.
