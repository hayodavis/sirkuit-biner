Memahami Bilangan Biner & IPv4

Pelajari bagaimana komputer memproses angka menggunakan sakelar digital dan bagaimana ia diterapkan pada alamat IP.

1. Apa itu Bilangan Biner?

Manusia berhitung menggunakan 10 angka (0-9) yang disebut Desimal. Namun, komputer hanya memahami dua kondisi kelistrikan: Ada Arus (1) dan Tidak Ada Arus (0). Sistem dua angka ini disebut Biner (Basis 2).

Setiap satu angka 0 atau 1 disebut Bit. Kumpulan dari 8 Bit disebut 1 Byte.

2. Alamat IPv4

IPv4 (Internet Protocol version 4) adalah alamat untuk perangkat di jaringan komputer. IPv4 terdiri dari 32 bit yang dibagi menjadi 4 Oktet (1 oktet = 8 bit), dipisahkan dengan tanda titik.

Desimal: 192 . 168 . 1 . 10
Biner: 11000000 . 10101000 . 00000001 . 00001010

3. Cara Konversi Biner ke Desimal

Dalam 1 oktet (8 bit), nilai dihitung dari kanan ke kiri sebagai perpangkatan angka 2. Jika bit bernilai 1 (Hidup), angkanya dijumlahkan. Jika 0 (Mati), nilainya diabaikan.

Bit ke-8Bit ke-7Bit ke-6Bit ke-5Bit ke-4Bit ke-3Bit ke-2Bit ke-1
1286432168421
10101000

Contoh Perhitungan Biner "10101000":

=> (1x128) + 0 + (1x32) + 0 + (1x8) + 0 + 0 + 0

=> 128 + 32 + 8 = 168

4. Cara Konversi Desimal ke Biner

Gunakan metode Pengurangan dengan Nilai Tempat (128, 64, 32, 16, 8, 4, 2, 1). Jika angka bisa dikurangi, tulis 1 dan kurangi angkanya. Jika tidak bisa dikurangi, tulis 0.

Contoh: Ubah angka 192 ke Biner!

  • 192 - 128 = 64 (Bisa -> Tulis 1)
  • 64 - 64 = 0 (Bisa -> Tulis 1)
  • 0 - 32 (Tidak -> Tulis 0)
  • Karena sisa sudah 0, bit selanjutnya otomatis 0.
Hasil Biner: 11000000

Panduan Bermain Biner Ngebut

Tujuan: Balapan mobil adu cepat menjawab soal biner. Tim pertama yang menjawab 3 kali dengan benar akan menyentuh garis finish dan menang!

  1. Pembentukan Tim: Guru memilih 5 orang siswa untuk mengisi masing-masing tim (TIM A & TIM B).
  2. Cara Menjawab: Kelima siswa berbaris, lalu maju secara bergantian (estafet) untuk menekan jawaban di perangkat/layar.
  3. Aturan Main: Cocokkan angka desimal yang ada di tombol dengan "Target Biner" di layar utama.
  4. Syarat Menang: Setiap jawaban benar akan memajukan mobil. Tim pertama yang mendapat 3 Skor (garis finish) menjadi pemenangnya.
  5. Penalti: Hati-hati! Jika salah menjawab, mesin mobil akan "Mogok" dan target soal akan langsung diacak ulang.

Cara Menghubungkan ke Google Sheets

Ikuti langkah ini untuk membuat sistem rekap nilai otomatis menggunakan Google Apps Script:

  1. Buka Google Sheets dan buat spreadsheet baru (misal: "Rekap Nilai Jaringan Dasar").
  2. Buat header pada baris pertama kolom A, B, C, D: Nama, Materi, Nilai, Tanggal.
  3. Klik menu Ekstensi > Apps Script.
  4. Hapus semua kode yang ada, lalu paste kode di bawah ini:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var nama = e.parameter.nama;
  var materi = e.parameter.materi;
  var nilai = e.parameter.nilai;
  var tanggal = e.parameter.tanggal;
  
  sheet.appendRow([nama, materi, nilai, tanggal]);
  
  return ContentService.createTextOutput("Success").setMimeType(ContentService.MimeType.TEXT);
}
  1. Klik tombol Simpan (ikon disket).
  2. Klik tombol Terapkan (Deploy) > Deployment Baru.
  3. Pilih jenis Aplikasi Web (Web App).
  4. Beri deskripsi. Pada bagian "Yang memiliki akses", pilih "Siapa saja (Anyone)".
  5. Klik Terapkan. Berikan izin otorisasi jika diminta (Lanjutkan > Buka tidak aman).
  6. Copy URL Aplikasi Web yang muncul, lalu paste ke kotak input di halaman Kuis MPI ini.
